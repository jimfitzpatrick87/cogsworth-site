Cogsworth privacy policy

Last updated: 8 November 2026

What Cogsworth accesses

With the user's permission, Cogsworth uses two read-only Google permissions: read Gmail messages and settings (gmail.readonly) and view Google Calendar (calendar.readonly). It never requests permission to send, delete, change or organise email or calendar data.

How the data is used

Cogsworth reads email and calendar data only to show the user their own daily priorities, bills and weekly review on their own computer. Processing, including any AI summarising, happens locally on that computer.

Where the data goes

Email and calendar content is not sent to the developer or any third party, is not sold, and is not used for advertising or to train AI models. Any diagnostics hold only counts, timings and error types, never message or event content. Cogsworth's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

The access token and any cached data are stored only on the user's computer. The user can remove Cogsworth's access at any time from their Google Account (Security, Third-party connections), and deleting the app's data folder removes everything it stored.

Contact

Questions can be raised through the GitHub profile that hosts this page.
